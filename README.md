# Telangana Tourism Database System

A comprehensive relational database project designed for managing and analyzing Telangana Tourism data using MySQL and Python for Exploratory Data Analysis (EDA).

# 📌 Project Overview

This project focuses on developing a relational database system to support data-driven decisions for Telangana's tourism sector. It consists of:

Database schema design and implementation using MySQL.

EDA using Jupyter Notebook to derive insights from the tourism dataset.

# 🗃️ Database Features

Schema Design: Designed multiple interrelated tables such as Districts, Attractions, Visitors, and Ratings.

Data Insertion: Populated tables with sample data representing real-world tourism statistics.

SQL Queries: Implemented retrieval, aggregation, and filtering queries to gain insights like:

Most visited attractions

District-wise tourism trends

Visitor demographics and feedback

# 📊 Exploratory Data Analysis (EDA)

Performed EDA in Jupyter Notebook using:

Pandas for data manipulation

Matplotlib and Seaborn for data visualization

# Key EDA Outputs:

Visitor trends by year and district

Most popular attractions

District-level heatmaps and charts

Rating distributions and visitor feedback analysis

# 🛠️ Technologies Used

MySQL – Database development

Python (Jupyter Notebook) – Data analysis and visualization

Libraries: Pandas, Matplotlib, Seaborn
